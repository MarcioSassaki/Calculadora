🧮 Calculadora Simples em Python

Um script em Python desenvolvido via terminal para realizar operações matemáticas básicas entre dois números, com validação para divisão por zero e escolha de operação.

🎯 O que o código faz?

Solicita o primeiro número ao usuário.

Apresenta um menu para escolha da operação (+, -, *, /).

Solicita o segundo número.

Realiza o cálculo correspondente e exibe o resultado final na tela.

Trata exceções simples, como tentativa de divisão por zero ou digitação de operação inválida.

🧠 O que pratiquei neste projeto?

Conversão de tipos de dados de entrada para número decimal (float()).

Estruturas condicionais aninhadas (if, elif, else).

Operadores aritméticos básicos (+, -, *, /).

Verificação de valores nulos com is not None.

💻 Como executar

Certifique-se de ter o Python instalado e rode o arquivo no terminal:

python nome_do_arquivo.py
